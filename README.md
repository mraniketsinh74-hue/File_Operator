# File_Operator
Personal Journal
Project Description
Personal Journal is a simple Python project that allows users to save and manage daily journal entries in a text file.

Features
 Add a new journal entry
 View all saved entries
 Search entries using a keyword
 Delete all journal entries
 Simple menu-driven program

Technologies Used
 Python
 File Handling
 Object-Oriented Programming (OOP)
 Date and Time Module

File Used
- "journal.txt" – Stores all journal entries.

How to Run
 Open the project in VS Code.
 Run the Python file.
 Select an option from the menu.
 Follow the instructions displayed on the screen.

Menu
 Add Entry
 View Entries
 Search Entry
 Delete Entries
 Exit
 
Advantages
Easy to use.
Saves entries permanently in a text file.
Helps organize daily notes.
Simple project for Python beginners.
Demonstrates practical use of file handling and OOP concepts.
Future Improvements

Edit existing journal entries.
Delete a specific entry instead of all entries.
Password protection for privacy.
Export journal entries to PDF.
Add categories or tags for entries.
